# 🎬 Firebase Movie - Tidy Edition

Improved version of firebase_movie dengan dokumentasi lengkap, best practices, dan template berkontribusi.

## ✨ Fitur Utama

- 🎥 **Browse Movies** - Jelajahi katalog film dari API eksternal
- ❤️ **Favorite List** - Simpan dan kelola daftar film favorit
- 🔐 **Firebase Auth** - Sistem login/register yang aman
- ☁️ **Firestore** - Sinkronisasi data real-time ke cloud
- 📱 **Responsive UI** - Design yang optimal untuk berbagai ukuran device

## 🛠️ Tech Stack

- **Framework**: Flutter
- **Language**: Dart
- **Backend**: Firebase (Auth, Firestore, Cloud Storage)
- **API**: RESTful API untuk data film

## 🚀 Quick Start

```bash
git clone https://github.com/Triyan31/firebase_movie-tidy.git
cd firebase_movie-tidy
flutter pub get
flutter run
```
